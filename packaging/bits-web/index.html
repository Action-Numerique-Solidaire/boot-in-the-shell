« Télécharger » récupère et vérifie une image sur le serveur sans changer le menu de démarrage réseau : pratique pour préparer à l'avance une image de plusieurs gigaoctets. Activer une image puis « Appliquer au PXE » : elle est téléchargée si besoin, vérifiée, puis ajoutée au menu. Désactivée, elle en est retirée ; le fichier téléchargé est conservé. Le menu n'a pas de choix par défaut : un poste démarré sur le réseau attend qu'on choisisse.
Pour une image téléchargée, le serveur vérifie s'il en existe une version plus récente (Killbit en publie une à chaque construction) : « Mettre à jour » la télécharge, la vérifie et, si l'image est servie, la publie aussitôt.
Windows : Microsoft ne publie que des liens valables 24 h et refuse de les fournir au serveur. Le lien est obtenu dans un navigateur puis collé dans la carte Windows (étapes affichées dans la carte). L'ISO est vérifiée avec l'empreinte publiée sur la page de Microsoft.
