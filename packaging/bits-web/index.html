« Télécharger » récupère et vérifie une image sur le serveur sans changer le menu de démarrage réseau : pratique pour préparer à l'avance une image de plusieurs gigaoctets. Activer une image puis « Appliquer au PXE » : elle est téléchargée si besoin, vérifiée, puis ajoutée au menu. Désactivée, elle en est retirée ; le fichier téléchargé est conservé. Le menu n'a pas de choix par défaut : un poste démarré sur le réseau attend qu'on choisisse.
